3 Tips for Prompting Code Generation
Specify Separation: Explicitly mentioning "three separate files" prevents the AI from lazily bundling the CSS and JavaScript inside the HTML file using <style> and <script> tags.

Define Sanitization: Asking the AI to "sanitize the input" forces it to write code that handles spaces, trailing commas, or letters without crashing.

Mention State Management: Adding "array cloning" ensures the AI remembers that QuickSort often mutates arrays in-place, which would otherwise accidentally ruin subsequent runs on the page.
